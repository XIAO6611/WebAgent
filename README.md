# 多模态 Web Agent

本仓库包含一个基于 Chrome Extension Manifest V3 的多模态网页 Agent。当前主要插件代码位于 `webagent/`，支持通过视觉大模型观察网页、执行网页操作、读取本地知识库，并针对求职/申请类网页提供专门的自动填表流程。

## 主要能力

- 通用网页 Agent：根据用户任务进行页面观察、规划、点击、输入、滚动、提取文本，并可生成 Markdown 报告。
- 表单填写模式：当任务包含“填表、填写、表单、简历、投递、申请、application、apply、form、resume、cv”等关键词时，自动进入安全填表流程。
- 简历解析：支持在插件设置页粘贴简历文本、上传 `.md/.txt` 文件，或上传简历图片解析个人信息。
- 个人知识库：解析出的姓名、电话、邮箱、学校、专业、学历、期望岗位等信息会合并到本地知识库，并可手动编辑。
- 知识库更新：用户修改表单后，可让插件对比当前表单和已有知识库，选择是否保存新增或修正的信息。
- 人工接管：遇到登录、验证码、安全验证或需要用户确认的页面时，Agent 会暂停并等待人工处理。

## 目录结构

```text
WebAgent/
├── webagent/                 # 当前 Chrome 插件源码
│   ├── manifest.json
│   └── src/
│       ├── background/       # 后台任务控制、提示词、Agent 循环、表单填写流程
│       ├── content/          # 页面 DOM 扫描、动作执行、表单扫描/填充、弹窗注入
│       ├── services/         # 大模型 API 调用、本地知识库读写
│       ├── ui/               # popup 和 options 页面
│       └── utils/            # 日志、知识库占位符替换
├── decument/                 # 设计和过程文档
├── report/                   # 汇报材料
├── test/                     # 测试记录
└── future.md                 # 后续规划
```

## 快速启动

> 注意：开发调试时不要点“打包扩展程序”。“打包扩展程序”只会生成 `.crx` 和 `.pem` 文件，不会自动把插件安装到 Chrome 扩展列表里。请点击“加载未打包的扩展程序”，并选择 `webagent` 目录。

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库下的 `webagent` 文件夹，也就是 `D:\cursor\WebAgent\webagent`。
5. 点击浏览器工具栏中的 Web Agent 图标，进入插件弹窗。
6. 点击“配置 API、知识库和简历”，填写智谱 API Key。
7. 在设置页粘贴简历文本、上传 `.md/.txt` 简历，或上传简历图片并点击解析。
8. 确认知识库字段后点击“保存全部设置”。
9. 打开一个真实网页，在插件弹窗输入任务并点击“开始”。

修改 `webagent/src/background/*`、`webagent/manifest.json` 或 content script 后，需要回到 `chrome://extensions/` 点击该插件的“刷新”按钮，再重新打开测试网页。

## 填表功能检验建议

1. 准备一个包含常见字段的网页表单，例如姓名、手机号、邮箱、学校、专业、学历、期望岗位等。
2. 在设置页导入简历并解析，确认知识库中至少存在 `name`、`phone`、`email`、`school`、`major` 等字段。
3. 打开表单页，在 popup 输入：`根据我的简历帮我填写当前求职表单`。
4. 点击“开始”，等待 Agent 填写字段。
5. 检查页面弹窗提示，确认 Agent 停在提交前，没有自动提交。
6. 手动修改某个字段后，打开 popup 点击“更新知识库（当前表单）”。
7. 在页面弹出的知识库更新建议中勾选要保存的字段，点击“保存勾选项”。

## 注意事项

- 插件不会自动点击提交、保存、下一步、投递等高风险按钮，填完后需要用户手动检查和提交。
- 登录、验证码、人机验证、短信码等页面状态会触发人工接管。
- 插件数据保存在 Chrome 本地 `chrome.storage.local`，不会自动同步到仓库。
- 当前模型接口使用智谱 `open.bigmodel.cn`，需要可用 API Key 和网络访问。
